Common Approaches

The goal is to have a reasonable safeguard(s) in place to mitigate opportunities for unauthorized external sharing of sensitive information.

These are just some examples to help you think through options based on your process — not a required list. Send us a message if you’re unclear — we’re glad to help!

  • View-only document access
  • Secure document delivery — forms, links, API
  • Company-managed devices — blocking access to personal email, cloud storage sites, USB drives
  • Outbound email quarantine on specific messages (e.g. outbound + attachments + sent to external or personal domain)
  • Document watermarking — www.aquamark.io or equivalent
  • Attachments route automatically to a CRM or equivalent, limiting human access
  • DLP (Data Loss Prevention) software — detects sensitive content by pattern and blocks it from leaving, across email, uploads, and cloud sync
  • CASB (Cloud Access Security Broker) — restricts downloads or syncing from cloud storage to unmanaged devices
  • Enterprise browser or browser isolation tools — disables downloads, copy/paste, or screenshots within specific apps
  • Web/DNS filtering — a network-level rule (via a firewall, secure web gateway, or a DNS filtering service) that blocklists domains like gmail.com, outlook.com, yahoo.com on company networks or company-managed devices. Simplest, most common for smaller shops.
  • Browser management policies — Chrome Enterprise or Edge for Business lets IT push a policy restricting browser sign-in to only company-domain accounts, or block navigation to specific URLs entirely. Common if the company’s already using Google Workspace or Microsoft 365 centrally.
  • “Tenant restrictions” — Microsoft and Google both let admins allow their own company’s version of Gmail/Outlook while blocking any personal account of the same app, even in the same browser tab. So a rep can use their work Gmail freely but literally cannot log into a personal Gmail on that device. This is what a CASB typically enforces.
  • MDM/endpoint management (Intune, Jamf) — pushes any of the above as a device-level policy, so it applies regardless of network.
